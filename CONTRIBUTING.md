# Contributing

Hermes Control Surface started as a personal dashboard for a real local machine.

The project is still small, and that is intentional. The goal is to keep it calm, useful, and easy to understand while slowly adding better ideas.

Contributions are welcome, especially in these areas:

- cleaner Debian / Ubuntu installation paths
- better hardware and service detection
- more optional cards and integrations
- mobile layout refinements
- clearer English and Chinese documentation
- safer defaults for public sharing

Please keep changes small, readable, and easy to review.

---

# 参与贡献

Hermes Control Surface 最初是为一台真实本地机器做的个人控制面板。

这个项目目前仍然很小，这也是有意保持的方向。目标是让它安静、实用、好理解，然后慢慢把更好的想法加进来。

欢迎一起完善这些方向：

- 更清楚的 Debian / Ubuntu 安装流程
- 更好的硬件和服务检测
- 更多可选卡片和集成
- 手机端布局细节打磨
- 更自然的中英文文档
- 更安全的公开发布默认值

请尽量保持改动小、清楚、容易审查。
